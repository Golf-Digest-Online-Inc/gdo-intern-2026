デプロイ手順書

最終更新日：2026年8月14日

本手順書には本番環境（EC2、RDS等）に対する操作が含まれます。実施前に対象環境・作業時間帯を関係者と確認してください。

1EC2への接続

  1. 冗長化構成の場合、待機系（片方）のEC2インスタンスを停止する。
  2. 起動中のEC2インスタンスへログインする。

2Python 3.13のインストール

add-apt-repository ppa:deadsnakes/ppa
apt install -y python3.13
curl -sS https://bootstrap.pypa.io/get-pip.py -o get-pip.py
sudo python3.13 get-pip.py
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.13 100
apt remove python3-blinker
update-alternatives（複数バージョン共存時の切替設定）により、python3コマンドの実体をpython3.13に切り替える。

3アプリケーションの取得

cd /usr/share/nginx
git clone <リポジトリURL>

cd ./gdo-intern-2026/docker/flask/src
git clone のリポジトリURLは環境ごとに異なるため、実施時に確認が必要。

4依存パッケージのインストールと環境設定

python3 -m pip install --no-cache-dir -r requirements.txt
cp -p .env.example .env

.envファイルの設定値（接続先ホスト、認証情報等）を実環境に合わせて変更する。

.envに記載する接続情報・認証情報は機密情報にあたるため、値を第三者と共有する際はサンプル値への置換や匿名化を行うこと。

5データベースのセットアップ

PostgreSQLへ接続する。

export RDSHOST="intern-arch-val-test1-db.czyc599lq5ki.ap-northeast-1.rds.amazonaws.com"
psql "host=$RDSHOST port=5432 dbname=appdb user=appuser"

テーブル作成を実行

\i /usr/share/nginx/gdo-intern-2026/docker/postgresql/tables/items.sql
\i /usr/share/nginx/gdo-intern-2026/docker/postgresql/tables/orders.sql
\i /usr/share/nginx/gdo-intern-2026/docker/postgresql/tables/payments.sql

初期データを登録

\i /usr/share/nginx/gdo-intern-2026/docker/postgresql/data/items.sql
exit

6Nginxの設定

cd /etc/nginx
mv nginx.conf nginx.conf.org
vi /etc/nginx/sites-enabled/default

locationブロックに下記を追記する。

proxy_pass         http://localhost:5000;
proxy_set_header   Host              $host;
proxy_set_header   X-Real-IP         $remote_addr;
proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
index  index.html index.htm;

7ログ出力先の準備

cd /usr/share/nginx/gdo-intern-2026/docker/flask/src
mkdir -p /var/logs
chmod 777 /var/logs
