### Gitのバージョン確認

`git --version`

### ブランチ作成

`git checkout -b {ブランチ名}`

### 変更があるファイルを確認

`git status`

### 変更内容を確認

`git diff -- {ファイルパス}`

### コミット対象としてファイルをマーク

`git add {ファイルパス}`

### コミット（バージョン記録を登録）

`git commit -m "{メッセージ}"`

### ローカルからリモートリポジトリ（今回だとGitHub）に同期

`git push origin {ブランチ名}`

### リモートリポジトリ（今回だとGitHub）からローカルに同期

**ローカル側は同期したいブランチに切り替えていること！**

`git pull origin {ブランチ名}`

### 別なブランチをマージ（統合）する

`git merge {統合したいブランチ名}`
