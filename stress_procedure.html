stressコマンド インストール・実行手順書

最終更新日：2026年8月21日

stress（サーバーに意図的に高い負荷をかけて動作を検証するツール）は、CPU・メモリ等に高い負荷をかけるコマンドです。本番環境や共用環境で実行するとサービスに影響を及ぼす可能性があるため、実施前に対象環境・作業時間帯を関係者と確認してください。

1stressのインストール

sudo apt install -y stress
sudo権限（管理者権限）が必要な操作です。実行環境によってはaptの前に「sudo apt update」が必要な場合があります。

2インストールの確認

stress --version

バージョン情報が表示されれば、インストールは正常に完了している。

3負荷テストの実行

stress --cpu 2 --timeout 600

上記コマンドは、CPUに負荷をかけるプロセスを2つ起動し、600秒（10分）後に自動的に停止する。

オプション説明
--cpu NCPU負荷をかけるワーカープロセス数をNで指定する
--timeout N負荷テストを継続する秒数をNで指定する
負荷テストを途中で中断する場合は、実行中のターミナルで「Ctrl + C」を入力する。

4topコマンドによるCPU負荷の確認

負荷テストの実行中に、別のターミナルを開いて以下のコマンドを実行する。

top

表示された一覧の「%CPU」列で、stressコマンドが起動したプロセス（COMMAND列が「stress」）の負荷状況を確認する。

項目説明
%CPU各プロセスが使用しているCPU使用率
%Cpu(s)画面上部に表示される、システム全体のCPU使用率
COMMAND実行中のプロセス名（stressのワーカープロセスは「stress」と表示される）
topコマンドを終了する場合は「q」キーを入力する。
